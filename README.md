# TradingAI

AI-powered trading analysis project with a Binance-style trading interface.

## Getting started

1. Install Node.js (LTS).
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Build

```bash
npm run build
```

## Environment variables

If the project uses API keys or other secrets, create a local `.env` file and **do not commit it**. Use `.env.example` for non-secret variable names.

> Never commit exchange API keys, secret keys, seed phrases, passwords, or other credentials to GitHub.
